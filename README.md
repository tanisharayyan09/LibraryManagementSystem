# 📚 Library Management System

## 📌 About the Project

The Library Management System is a desktop application developed as part of my OOPS with Java coursework.

It helps manage library books efficiently using a JavaFX user interface and a MySQL database.

## ✨ Features

- 📚 Add Books
- 🔍 View Books
- 📖 Issue Books
- 🔄 Return Books
- 📊 Dashboard with Book Statistics
- 🗄️ MySQL Database Connectivity
- 🖥️ User-Friendly Graphical Interface

## 🛠️ Technologies Used

- Java 21
- JavaFX 21
- MySQL
- JDBC
- Apache Maven

## 🗄️ Database Details

- Database Name: `librarymanagement`
- Table Name: `lib_books`
- Connectivity: JDBC

## 📂 Project Structure

- `src/` – Java source code
- `pom.xml` – Maven configuration and dependencies
- `README.md` – Project documentation

## ▶️ How to Run the Project

1. Install JDK 21.
2. Install MySQL.
3. Open the project folder in VS Code.
4. Configure the MySQL database connection.
5. Install the required Maven dependencies.
6. Run the Java application.
